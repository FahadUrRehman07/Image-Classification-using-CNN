# CIFAR-10 Image Classification — ANN vs CNN

A reproducible deep-learning study comparing a fully connected neural network (ANN) with a convolutional neural network (CNN) on the CIFAR-10 image-classification dataset.

## 🎯 Objective

Demonstrate why convolutional architectures are better suited to image data by comparing:

- a dense ANN baseline
- a CNN with convolution, pooling, batch normalization, dropout, and data augmentation

## 📊 Dataset

CIFAR-10 contains 60,000 RGB 32×32 images across 10 classes:

airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck.

## 🧪 Evaluation Design

The notebook now uses a clean evaluation protocol:

```text
50,000 CIFAR-10 training images
        │
        ├── 45,000 training
        └── 5,000 validation
       
10,000 CIFAR-10 test images
        │
        └── untouched until final evaluation
```

The test set is **never used for model fitting or model selection**.

## 🧠 Models

### ANN Baseline

- Flattened 32×32×3 input
- Dense layers
- Dropout
- 10-class softmax output

### CNN

- Random horizontal flip
- Random rotation and zoom
- Convolutional blocks
- Batch normalization
- Max pooling
- Global average pooling
- Dropout
- 10-class softmax output
- Early stopping
- Learning-rate reduction
- Best-model checkpointing

## 📈 Evaluation

The notebook reports:

- training and validation accuracy/loss
- final untouched-test accuracy
- precision, recall and F1-score by class
- confusion matrix
- sample predictions

**Important:** historical metrics from the previous version of this notebook are no longer used because that version trained on the test set. Final metrics should be generated by running the corrected notebook from top to bottom.
